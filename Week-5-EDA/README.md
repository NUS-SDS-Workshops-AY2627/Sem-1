# **Into the Unknown: An Introduction to Exploratory Data Analysis (EDA) with Python and LLMs**

#### **9th September 2026, 7pm - 9pm**

Welcome to our first SDS workshop of the AY! The workshop is all about Exploratory Data Analysis (EDA). Ever worked with a dataset that was a little too messy for your liking, or felt unsure about where to begin exploring it? This workshop will guide you through those first steps. You will also have the opportunity to apply what you have learnt by exploring a messy dataset on your own!

## **Requirements**
For the workshop, we highly encourage you to use Google Colab during our code-along sessions. This will help prevent any version or package conflicts that you may encounter when running the code locally. 

If you have prior coding experience and would prefer to run the code locally using your own IDE, you are more than welcome to pull the workshop materials from this repository into your local folder! We recommend using Python version `3.13.x` or `3.14.x`, as other versions may give rise to package compatibility issues. Please also ensure that you have the following packages installed, as we will be using them during the session:
+ `pandas`
+ `numpy`
+ `matplotlib`
+ `seaborn`
+ `geopandas`
+ `WordCloud`

We recommend creating a virtual environment (`venv`) to install these packages. This will help keep your workshop dependencies separate from those used in your other projects and reduce the likelihood of version conflicts.
