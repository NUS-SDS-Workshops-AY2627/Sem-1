# Workshop Image Assets

The hand gesture images in this directory were generated using
OpenAI's image generation tools for use as demonstration materials
in this Computer Vision workshop.

These images are used to demonstrate concepts such as hand detection,
bounding boxes, IoU, non-maximum suppression, and hand landmark detection.

## Images

- `open_palm.png` — Open palm gesture
- `fist.png` — Fist gesture
- `peace.png` — Peace gesture

## Note

These are AI-generated images and do not depict real individuals.
